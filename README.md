# PowerFit Gym Website

A modern static multi-page gym website built using HTML and CSS.

## Features

- Responsive design
- Multi-page layout
- Modern UI
- Hero section
- Services page
- Pricing plans
- Contact page
- Mobile friendly navigation

---

# How To Run The Project

1. Download or clone the project.

2. Open the project folder.

3. Open `index.html` in your browser.

├── training.jpg
├── cardio.jpg
└── trainer.jpg
